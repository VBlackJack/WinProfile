# Security policy

## Supported versions

Only the latest published WinProfile release receives security updates.

## Reporting a vulnerability

Use the repository's private security-advisory reporting channel. Do not disclose a suspected vulnerability in a public issue, discussion, or pull request.

Include the affected version, Windows version, reproduction steps, expected and observed behavior, and any evidence that helps assess impact. Do not include credentials, profile data, registry exports, or other personal information.

Security reports are acknowledged after triage. Publication and remediation timelines depend on severity, reproducibility, and the availability of a safe fix.
